FOLIO BOOKSTORE - FINAL WORKING VERSION

1) Open Terminal in this folder.
2) Run:
   npm install
3) Run:
   npm start
4) Open in browser:
   http://localhost:3000

Important:
- Do NOT open index.html directly.
- Do NOT run a separate frontend server.
- This version serves frontend and backend together from port 3000.
